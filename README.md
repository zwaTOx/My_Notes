# MY_NOTES app

MyNotes is an application for creating, editing, and storing notes developed in the Python programming language. SQLite is used as the database, which makes it easy and fast to work with data. 

The application offers a clear interface created using the Tkinter library, which makes it accessible to users with different levels of technical training. 

With MyNotes, users can:

- Create new notes by saving them in the database.
- Edit existing notes.
- Delete unnecessary notes.
- View your notes in a convenient format.

MyNotes is the perfect solution for those who want to organize their thoughts and ideas in one place using a simple and effective application.
